## GitHub Pages
Envie `index.html`, `style.css`, `script.js` e a pasta `assets` para a raiz do repositório.
Depois: Settings → Pages → Deploy from branch → main → /(root) → Save.

## WhatsApp
No `script.js`, substitua `5551999999999` pelo número comercial real, com país + DDD + número, sem espaços ou símbolos.

Os SVGs em `assets` são imagens locais leves e podem ser substituídos futuramente por fotografias executivas reais mantendo os mesmos nomes.
